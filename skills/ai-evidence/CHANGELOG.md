# Changelog

## 0.1.0 (unreleased)

- Image pipeline: `analyze_image.py` (provenance and metadata evidence, stdlib only) and `score_evidence.py` (validation, weighting, HTML report).
- Evidence model: score 0-10 and weight 0-1 per item; two assessments (generated, edited with AI) with band and confidence; conclusive items decide and contradictions are reported as conflicts.
- Signals: Stable Diffusion, ComfyUI, Midjourney, SwarmUI, InvokeAI, Fooocus and NovelAI records; C2PA and IPTC/XMP source types; EXIF software and camera data; generator dimensions; file name patterns.
- Model visual inspection with weight caps per kind.
- `evals/evaluate_dataset.py` (with `--check` and a collecting guide, `evals/COLLECTING.md`): evaluates the automatic layers on a labelled image set. False-positive and detection rates with Wilson intervals, abstention rates, AUC, per-source false positives, a stripped-metadata condition, a deterministic dev/test split and per-evidence likelihood ratios with suggested weights (withheld below 30 images per class).
- Code pipeline (`analyze_code.py`): assistant configuration files, commit trailers and history shape from a log the user exports (git is never run; no author names or e-mails are read), placeholders, Markdown fences and chat replies in whole-line comments, residue in the README, and capped style signals (narrating comments, docstring uniformity, step comments, emoji). Python is parsed with `ast`; nothing is executed. Code wording and a "using AI for code is normal" notice in the report.
- `evals/GUIA-IMAGENES.es.md`: a practical Spanish guide to collecting the image test set, with a five-session plan, a pilot, 24 reusable prompts and the traps that spoil a dataset (HEIC, drag-and-drop downloads, AI editing tools mixed into the real folder).
- `evals/GUIA-TEXTOS.es.md`: a practical Spanish guide to collecting the text test set: six sessions, a pilot, 24 reusable topics in both languages, five instructions to vary the AI texts, the second-language writers group with a consent text, and the traps (smart punctuation from word processors, length and topic confounds, writers who sound like an assistant).
- `evals/GUIA-CODIGO.es.md`: a practical Spanish guide to collecting the code test set: six sessions, a pilot, the four human look-alike groups (formatter-driven, tutorial-style, template-based, AI-calling apps), 16 project ideas, how to copy projects without `.git`, the git-log export, and the rule that logs go to every group or to none.
- Evaluation harness for code: the unit is a project folder or a source file under `<label>/<source>/`, recognised even though each project has a README; optional per-project `git-log.txt` (the harness never runs git); firm rates, false positives and where each item fires on human projects by source, breakdowns by code size and main language, a size-confound warning and a missing-log notice in `--check`, and cleaned copies without assistant files, trailers and residue comments. Samples are only read: never run, never followed through symlinks.
- Evaluation harness for texts: the modality is inferred from the extensions; "firm" detection and false-positive rows (at least medium confidence), breakdowns by text length and language, where each item fires on real texts by source (the fairness check for second-language writers), a length-confound warning in `--check`, and cleaned copies (`--augment strip`) with the assistant residue removed.
- Every report and README now states that the tool does not accuse anyone and is for seeing, checking and learning.
- Text pipeline (`analyze_text.py`): residue left by chat assistants (strong) and style signals for English and Spanish (weak, capped together at 0.5), plus the model's reading with weight caps. Text wording, measurements and a text-specific disclaimer in the report.
- Group caps in `score_evidence.py`: style 0.5, pixels 0.5, model observations 1.0 per question, so correlated weak signals cannot add up to confidence.
- Optional pixel module (`analyze_pixels.py`, needs Pillow and NumPy): noise level and consistency, periodic upsampling artifacts, JPEG error level analysis. Heuristics checked on synthetic images only; every scored item is capped at weight 0.25 and refused for small images, graphics and low-quality JPEGs. Merged with `score_evidence.py --pixels`.
