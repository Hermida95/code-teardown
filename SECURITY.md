# Security

Both skills in this repository read untrusted input (code, bytecode, Docker images, image files) and are built so that nothing analyzed is ever executed. Each one documents what it guarantees and what it does not:

- [code-teardown](skills/code-teardown/SECURITY.md)
- [ai-evidence](skills/ai-evidence/SECURITY.md)

To report a problem, open a private security advisory on this repository, or an issue that describes the impact without publishing a working exploit.
